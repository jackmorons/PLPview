# Handoff: state of the PL app (2026-10-25)

Read this first in a new session. Then `VERSIONS.md` (status, dated decisions, changelog), then the spec you need.

## The project in one paragraph

PL is an app for Jack (powerlifter, mechanical engineer, Italy) that imports a training program from a strict-format
`.xlsx`, shows it week by week and day by day with loads computed from editable maxes, and (later) adds training tools.
One web codebase (Vite, plain JS, no framework, no TypeScript) wrapped by **Capacitor 8.5.3** into `ios/` (Xcode)
and `android/` (Android Studio). UI and program text are **Italian**. Jack wants to understand the project:
explaining as you build is part of the deliverable (`docs/PL-App-SPEC.md` §8).

**Branch:** `milestone-1-2` on `jackmorons/plpview` (holds milestones 1–3 plus the coach format). Not merged into
`main`, no PR. Last commit: `1523898`. Push access works (it was fixed during the session).

### Code map (`src/`)

| File | Role | Pure? |
|---|---|---|
| `parser.js` | bytes → model or error list; picks the format | yes |
| `parse-pl28.js` | PL28 format → schema-1 shape (`readV1`) → `expandV1` → schema 2 | yes |
| `parse-coach.js` | coach format (`training log` + optional `overall`, `Massimali`) → schema 2 | yes |
| `parse-common.js` | cell helpers, formula grammar, `{Squat .57}` placeholders, Massimali | yes |
| `model.js` | `SCHEMA_VERSION = 2`, week types, `expandV1`, `migrate`, `validateProgram` | yes |
| `resolve.js` | model + maxes → display strings, plates, `session()`, week-type labels | yes |
| `programs.js` | revisions (last 5), restore, carry-over of maxes/position, change summary | yes |
| `library.js` | the app's data (programs, active, maxes, positions) over a storage adapter | yes (adapter injected) |
| `storage.js` | Filesystem on device, localStorage in browser | **Capacitor** |
| `native.js` | file picker, share sheet, clipboard | **Capacitor** |
| `main.js`, `ui/*` | tabs: Sessione, Strumenti (placeholder), Note, Programmi; dialogs; errors screen | DOM |

**Rule:** only `storage.js` and `native.js` import Capacitor. Everything else must stay runnable in Node.

## Decisions already made (don't re-open them)

- Bundle id `it.jackmorons.plpviewapp`, app name "PL".
- Load placeholders use the **full lift name**: `{Squat .57}`. The letter rule in `PL-App-SPEC.md` §3.3 is superseded.
- Format detection: an `accessori` sheet → PL28 format (even if a `training log` sheet exists, as in `PL28.xlsx`);
  otherwise one `training log…` sheet → coach format.
- Week types: fixed list (`normale, scarico, transizione, ramping, intensificazione, picco, taper, entrata, test, gara`),
  case-insensitive, anything else is an error. Only in the PL28 format do `transizione/scarico/test` reduce accessory
  sets by 1 and add RIR +1 (`rirPlusOne`).
- PL28 vs coach "same sessions" test ignores main-lift names (`Squat stress` vs `squat`) and treats `—` as empty.
- Accessories display as written: `3x8-10` (not `3×8-10`).
- A day's first note is its banner and isn't repeated under the item. PL28-format files get their reminders
  ("Fai E solo se…", "Accessori già scalati di 1 serie: tieni RIR +1.") as that first note.
- Week buttons: 5 per row per block; 44 px tall but ~38 px wide on phones (prototype layout kept, flagged to Jack).
- The full dated list is in `VERSIONS.md` → v1 → Decisions.

## Rules from the spec that bite

- **Ask Jack before changing:** the RPE chart, default bar/plate settings, the light-week rule, anything in a format spec.
- Never change program strings or Jack's notation in the display.
- Keep `docs/FORMAT*.md` in sync with the parsers; they are the contract Jack writes files against.
- When a spec contradicts itself or a fixture, **check against the fixture first**, then propose a resolution and
  record it in `VERSIONS.md`. Jack's specs have had real contradictions every time.
- No network at runtime; fonts are bundled in `src/fonts/`.
- Header comment on every `src/` file (what it does, who calls it). Explain milestones to Jack in plain language.

   The fix is `"xlsx": "https://cdn.sheetjs.com/xlsx-0.20.3/xlsx-0.20.3.tgz"` in `package.json`, but
   cdn.sheetjs.com is **blocked from the cloud container** (403). Jack has to do it on his Mac, then `npm test`.
2. **Phone code never executed:** `storage.js` (Filesystem, Directory.Data), `native.js` (`@capawesome/capacitor-file-picker`
   with `readData: true`, Share via Cache file). Expect fixes in milestone 4.
3. **PL27 data:** some main-lift rows in its log (e.g. week 15 squat/panca) have empty E/F; the prescriptions exist
   only in `overall` without a reference. Shown as name + variant only. Only the coach can fix the file.
4. **Not built:** milestone 5 tools (back-off, RPE, RT counter, plate settings, ramping, timers), volume view
   (`FORMAT-COACH-SPEC.md` §6: per week, from items), JSON backup, the optional week-type filter, "Open in PL"
   from Files (P1), Android `content://` handling.
5. **Minimum Xcode / Android Studio versions** in the build docs are unverified (capacitorjs.com was blocked);
   the docs say "latest" and point to `npx cap doctor`.
6. Branch name `milestone-1-2` no longer matches its content; rename or merge when Jack decides.
